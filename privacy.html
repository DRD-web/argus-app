Règles de confidentialité - Argus n8n

Usage : Argus n8n est une application à usage strictement personnel. Elle n'est proposée à aucun autre utilisateur et n'accède qu'au compte Google de son auteur.

Données consultées : e-mails Gmail (lecture seule), Google Agenda, Google Tasks et Google Sheets du compte de l'auteur.

Traitement : les données sont traitées par une instance n8n exécutée localement sur l'ordinateur de l'auteur. Des extraits limités peuvent être transmis à l'API Google Gemini pour produire des résumés. Aucune donnée n'est vendue, partagée ou transmise à un autre tiers.

Conservation : les historiques d'exécution sont supprimés automatiquement après 7 jours.

Conformité : l'utilisation des données issues des API Google respecte les règles « Google API Services User Data Policy », y compris les exigences d'utilisation limitée (Limited Use).

Révocation : l'accès peut être retiré à tout moment depuis https://myaccount.google.com/permissions.
